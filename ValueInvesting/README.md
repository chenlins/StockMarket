# A 股健康检测工具

输入 6 位 A 股代码，工具会综合最新财务数据、估值、财务安全性、近 120 个交易日趋势与流动性，给出 0–100 分健康评分和逐项解释。

每次启动时，工具会在后台读取东方财富人气榜，按热度排名取前 500 只，并只保留总市值 500 亿以下的股票；若人气榜不足，再用飙升榜里同样符合市值条件的股票补齐。然后结合批量财报与 120 日行情运行完整五维评分。最终结果严格按健康分从高到低排列，页面展示前 10 只。点击排行中的股票即可查看完整检测结果。上次成功排行会保留到本地缓存，因此再次启动时可以先查看旧结果并等待刷新。

## 启动

Windows 用户可双击 `启动股票健康检测.bat`。也可以手动运行：

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
.\.venv\Scripts\python main.py
```

默认监听所有本机网络接口。本机可打开 <http://127.0.0.1:8788>，同一局域网内的其他设备可通过
`http://服务器局域网IP:8788` 访问，例如 `http://192.168.1.100:8788`。

可在 Windows PowerShell 中运行 `ipconfig`，从当前联网网卡的“IPv4 地址”查看服务器局域网 IP。
首次启动时如果 Windows 防火墙弹出提示，请允许 Python 通过“专用网络”；不要对不受信任的公用网络开放此端口。

## 评分口径

- 盈利与成长：30 分，关注 ROE、净利率、营收增长、净利润增长和经营现金流。
- 估值：20 分，关注 PE、PB；亏损或极高估值会扣分，但不单独决定结论。
- 财务安全：20 分，关注资产负债率、流动比率和现金流质量。
- 趋势与波动：20 分，关注均线结构、120 日收益、最大回撤和年化波动率。
- 流动性与特殊风险：10 分，关注成交额、换手率、停牌及 ST 标记。

数据缺失时使用中性分，不将缺失直接视为经营恶化；报告会降低“数据可信度”并列出缺失项。阈值与权重位于 `config.yaml`。

## API

`GET /api/health/{code}`，例如：

```text
http://127.0.0.1:8788/api/health/600519
```

- `GET /api/top-health`：读取启动筛选状态和 Top 10。
- `POST /api/top-health/refresh`：手动重新筛选。

热度候选数、市值上限、最终展示数量和并发数可以在 `config.yaml` 的 `screening.hot_limit`、`screening.max_market_cap_yi`、`screening.top_count`、`screening.workers` 中调整。

## 数据与免责声明

公开数据通过 AkShare 获取，并缓存在本机 SQLite 中。不同数据源的更新时间和口径可能不同，页面会展示数据时间、来源及缺失项。

本工具仅用于学习和研究，不构成任何投资建议。健康分是规则模型的结果，不代表未来收益，也不能替代财报核验、行业比较和个人风险判断。
